## 2026-09-29 补建 BLUEPRINT / CHANGELOG / AGENTS 三份文档

**起因**：用户问「这个怎么没有按照 vibe-app 标准写文档」。仓库只有给插件市场看的发布说明、一份写给 AI 的功能-代码对照、一堆按日期的 spec / plan，没有一份「现在是什么」的功能全貌，也没有交接入口。
**改成**：新增 `docs/BLUEPRINT.md`（当前功能与数据格式）、本文件（为什么变）、根目录 `AGENTS.md`（先读什么、命令、代码地图、坑）。本条之前的历史只补记了出生和 0.9.x 两次改动，更早的「为什么」散在 `docs/superpowers/specs/` 和根目录 CHANGELOG.md 里。
**没选的路**：把根目录 CHANGELOG.md 改写成「为什么」格式——不行，那份是插件市场的发布说明，面向装插件的人，两份读者不同。

## 2026-09-29 按文件夹隐藏编辑器标记（0.9.4）

**起因**：用 cjtag 给一个仓库导了一条 90 步的教学链路后，代码里满屏都是标签。用户原话：「现在我们做的这个教学功能。导致便签爆炸。会看的很难受。所以增加按文件夹隐藏。」
**根因**：原来只有全局的「隐藏 / 显示标签标记」开关，要么全亮要么全灭；教学链路和自己平时的标签混在一起，没法只关掉一批。
**改成**：文件夹上加眼睛按钮，隐藏它连同全部子文件夹在编辑器里的标记，侧边栏照常列出；从侧边栏跳到的那一条、顺读当前步临时显示。cjtag 同步加 `hide / show --folder`。
**没选的路**：
- 隐藏时把标签从行号跟踪里也拿掉——不行，取消隐藏时标签已经跟代码跑偏了。
- 临时显示那一条直到切换文件就清掉——跳进别的文件看一眼再 Alt+← 回来，检查点就没了，追链路时正需要它；改成一直显示到下一次从侧边栏跳转为止。
- 隐藏状态存在各人的工作区设置里——命令行没法设，导入教学链路时不能顺手隐藏；存进 `store.json` 文件夹上。

## 2026-08-30 顺读模式 + cjtag 命令行（0.9.0）

**起因**：想让 AI 按阅读顺序批量埋标签，生成「一步步读」的代码教程。此前只能手改 `store.json`，id、时间戳、三种锚点都要自己填，填错了标签就找不回行。
**改成**：文件夹上加 ▶「顺读此文件夹」逐步播放；新增命令行 `cjtag`，只给 `{folder, file, line, note}` 就能写入，其余字段从源文件对应行算出来；扩展监听 `store.json`，外部写完侧边栏立即刷新。
**没选的路**：让 AI 直接写 `store.json`——锚点算错就会被判可疑或跳错行，而且格式一改所有调用方跟着坏；命令行把格式收在扩展这一侧。
**影响**：之后用户又否掉了「只排顺序让人按 Alt+] 顺读」的教学用法（看完学不会自己追），教学链路改成每步写「下一步用什么跳转」的引导式检查点，顺读只当复习用。这部分规矩在 cjt skill 里，不在本仓库。

## 2026-06 出生：从 CodeTour 改造成代码标签

**起因**：啃不熟的代码时，过几天就找不回当初真正要紧的那几行；想要私人的、可点回去的行批注，代码怎么改都跟着走，不往源码里写东西，也不需要分享给别人。
**改成**：以 Microsoft CodeTour（MIT）为底，把「导览」改成「标签 + 文件夹树 + 跳转链接」，数据放工作区的 `.code-jump-tags/store.json`。
**没选的路**：直接用 CodeTour——它的产品形态是「录一段导览给别人看」，和「私人批注、点回去」不是一回事（README 开头那句「它不是导览」就是这个意思）。其余当时考虑过的方案，补建本文件时已无记录可查。
