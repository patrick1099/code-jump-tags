# Code Jump Tags 蓝图
> 活蓝图：正文永远是当前真相，改了就覆盖。只讲功能不讲实现。
> 重构照本文行为契约重写即可；未列为硬约束的一切都是实现细节，可自由更改。

## 1. 一句话

VS Code 扩展。读不熟的代码时，把私人批注钉在某一行上：代码怎么挪它都跟着走，
之后从侧边栏的树或一条链接点回去。不往源码里写任何东西，不需要分享给谁。
另带一个命令行工具，让脚本 / AI 批量写标签，做成「按顺序一步步读」的代码教程。

## 2. 功能与行为 + I/O 契约

### 打标签与改标签
- 开「编辑模式」→ 行号左边出现 `+`；点 `+` 写一句话提交 → 这一行多一条标签。每次提交都新建一条，一行可以挂多条。
- 标签在编辑器里的样子：行号栏一个准星图标；批注首行显示在行上方（默认，可点）或行尾（每条标签自己切换）；悬停该行弹出这一行全部标签的完整批注，每条带「✎ 编辑」。
- 同一行多条标签在行上方并排成 `⌖ A | ⌖ B`，按创建时间先后排；点哪条编辑哪条。
- 改批注：点行上方的批注、悬停里的 ✎、或在树里重命名。编辑气泡可保存 / 取消 / 删除。

### 侧边栏的树
- 独立的活动栏入口，视图叫「标签」。文件夹可任意层级嵌套；标签和文件夹都能拖放归类、排序，支持多选批量拖、删、复制链接。
- 新标签默认进根上的「未分组」文件夹。给它改名或拖进别的文件夹，它就变成普通文件夹，下次新建标签时再自动建一个新的「未分组」。
- 点树里的标签 → 打开文件、跳到那一行（按内容找回后的真实位置）。
- 删除进回收站（最多保留 50 项，新的在前），可恢复整项，也可以从删掉的文件夹里单挑任意一层恢复。删除前默认确认，确认框里可以选「不再询问」。

### 标签跟着代码走
- 在 VS Code 里编辑：上方插删行、剪切粘贴整行、就地改这一行，标签都留在原来那行代码上；撤回后也能归位。
- 在 VS Code 看不见的地方改了文件（别的编辑器、git pull、关着窗口时被改）：按标签建立时记下的行内容找回位置；找不回或内容对不上的，标成**可疑**——行号栏变成灰色 `?`，悬停显示「原身份 / 现内容」对照，给出「采纳新位置」（只有找到候选行时才给）和「移到光标行」。可疑标签同时出现在树顶的「⚠ 待处理」分组里。
- 可疑检查只在几个触发点跑：打开 / 切换文件、窗口重新获得焦点、文件被外部改动（这三个默认开），保存、编辑停顿后（这两个默认关）。另有「重新校验当前文件」命令手动触发。
- 标签的「身份」（建立时那一行的内容）只有两种情况会被改写：新建标签、用户明确操作（移到光标行 / 粘贴到此行 / 采纳新位置）。自动跟踪永远不改它。

### 移动标签
- 树里「剪切标签」→ 编辑器右键「粘贴标签到此行」；或树里「移到光标行」一步到位。
- 显式移动可以撤回 / 恢复（当前会话内，最多 20 步）。视图标题栏常驻撤回 / 恢复两个按钮。

### 随手私记（`//me:`）
- 在行尾写 `<行注释符>me: 一句话`，光标一离开这一行，这段文字就从代码里消失，存进标签库，行尾改显示成一行斜体小字；光标回到这一行又展开成原文，可以就地改。清空 `me:` 后面的内容再离开 = 删掉这条（进回收站）。
- 随手私记没有行号栏图标、不参与可疑检查、不进顺读，默认也不出现在侧边栏（可开一个只读的「💬 随手」汇总组）。
- 可以在随手私记和正式标签之间互相转换（提权 / 降格）。
- 标记词可以配置，注释符跟着文件语言走（`//`、`#`、`--` 等）；排除名单里的路径不折叠。

### 顺读
- 任意一层文件夹上的 ▶「顺读此文件夹」：按树里的顺序（含全部子文件夹，深度优先）逐条走正式标签。每一步跳到该行，行旁的气泡显示 `Step #i of N` 和批注；气泡默认折叠，展开 / 折叠状态在翻页时保持。
- `Alt+]` 下一步、`Alt+[` 上一步，气泡标题栏也有上一步 / 下一步 / 结束按钮；第一步没有「上一步」，最后一步没有「下一步」。
- 开始顺读时，如果编辑模式开着就先关掉它。

### 按文件夹隐藏标记
- 文件夹行上的眼睛按钮（右键菜单里也有）：隐藏后，这个文件夹连同全部子文件夹的标签不在编辑器里显示——行号栏图标、行上方 / 行尾的批注、悬停都没有。侧边栏照常列出、照常能点。
- 隐藏的文件夹在树里显示灰色闭眼图标，后面标「标记已隐藏」；被上级带着隐藏的子文件夹标「随上级隐藏」。
- 例外：最近一次从侧边栏跳到的那一条（一直显示到下一次从侧边栏跳转）、以及顺读的当前一步，会临时显示出来。
- 隐藏的标签在代码编辑时照样跟着行走。
- 另有全局的「隐藏 / 显示标签标记」开关，一次管全部。

### 复制链接
- 单条标签或整个文件夹都能复制成 Markdown 链接（文件夹 = 每条一行）。在 VS Code 外点链接会拉起 VS Code 并跳到那一行。

### 命令行工具 `cjtag`
- 给「文件 + 行号 + 文件夹路径 + 一句批注」，其余字段（身份、锚点、id、时间）自动补齐写进标签库。扩展开着时侧边栏立即刷新，不用重载窗口。
- 子命令：`import <file.json|->`（批量）、`add`（单条）、`list [--folder]`、`clear --folder`（整个文件夹进回收站）、`hide / show --folder`（隐藏 / 显示编辑器标记）、`--ai-help`。
- 批量导入逐条校验，任何一条不过就整批拒绝、不写入；导入**不去重**，同一份清单导两次会出重复标签。

**I/O / 数据契约（换语言必须逐字保留）**

- **标签库文件**：`<工作区根>/.code-jump-tags/store.json`，UTF-8 JSON。
  `{"version": 1, "tree": [节点...], "trash": [{"node": 节点, "deletedAt": ISO时间}...]}`
  - 文件夹节点：`{"type":"folder","id","title","children":[...]}`，可选 `inbox: true`（「未分组」收件箱，根上最多一个）、`hidden: true`（隐藏编辑器标记）。
  - 标签节点：`{"type":"tag","id","note","file","line","createdAt"}`；`file` 是相对工作区根、正斜杠分隔的路径，`line` 从 1 开始。可选：`original`（身份：建立 / 用户显式重设时那一行 trim 后的文本）、`text`（当前锚点文本）、`pattern`（旧式行内容正则，链接和老数据兼容用）、`notePosition: "above"|"end"`、`inline: true` 与 `inlineMarker`（随手私记）、`witnessed`。
  - 根上不允许散放标签；读到散放标签就收进「未分组」。老数据缺 `text` / `original` 时按已有字段回推补齐。旧目录 `.lodestar/store.json` 存在而新文件不存在时，读入并迁移到新位置。
  - 外部改写这个文件 → 扩展自动重新载入。
- **跳转链接**：`vscode://patrick1099.code-jump-tags/goto?file=<相对路径>&line=<行号>[&pattern=<正则>]`，Markdown 形态是 `[批注首行](链接)`。
- **cjtag 输入**：扁平数组，每项 `{"folder": "A/B" 或省略, "file": 相对工作区根, "line": 整数, "note": 非空, "text": 可选}`。`folder` 用 `/` 分层、逐级复用同名文件夹或新建；省略就进「未分组」。数组顺序 = 阅读顺序。读源文件时 UTF-8 解不出来就按 GBK 解。
- **cjtag 输出**：stdout 只有一行 JSON 信封 `{"ok", "data", "error", "meta"}`；失败写 stderr。退出码 0 成功，1 运行 / 业务失败，2 参数错误。工作区根 = 从 `--cwd`（默认当前目录）往上第一个含 `.git` 或 `.code-jump-tags` 的目录。
- **设置项**（前缀 `codeJumpTags.`）：`showMarkers`、`confirmDelete`、`exclude`（glob 列表）、`recheckOn.{open,focus,externalChange,save,idle}`、`inlineNote.{enabled,markers,showSummaryGroup}`。

## 3. 边界 / 明确不做

- 不往源码里写任何东西；随手私记的原文在离开那一行时就从源码里拿掉。
- 不做多人协作 / 共享：要共享就自己提交 `store.json`，扩展不管同步。
- 顺读只是按顺序走标签，不做 CodeTour 那种导览录制、分支、Git 版本绑定之类的功能。
- 不在每次按键时跑可疑检查，只在触发点跑。

## 4. 硬约束 + 重构自由声明

- 离线运行；数据只在工作区里的 `store.json`，不上传。
- 删除一律先进回收站，不直接销毁。
- 标签「身份」只有新建和用户显式操作才能改，任何自动路径都不许改。
- 编辑器里显示的位置和点击跳转的位置必须一致（走同一套位置解析）。
- 可移植架构约束：标签树、位置找回、可疑判定、链接和命令行的读写这类逻辑不依赖编辑器 API，能脱离编辑器单独测试；命令行工具不依赖编辑器，和扩展只通过 `store.json` 交换数据。
- **以上未列出的一切均为实现细节，重构可随意更改。**

## 5. 功能痛点 / 易错点

- **「没找到」和「原地命中」看起来一样**：位置找回在找不到时会退回原行号，此时原行可能已被邻居行顶上来。自动路径如果拿这一行去刷新锚点，锚点就被邻居污染，撤回后标签也回不去。
- **实时编辑和冷恢复是两套逻辑**：编辑器里亲眼看见的改动要按位置精确跟；只有没看见的改动才按内容模糊找。把模糊搜索用在实时重绘上，一改行内容标签就会跳到文件里另一行一模一样的代码上（比如重复的注释行）。
- **隐藏 ≠ 不跟踪**：隐藏只影响显示；行号跟随、可疑检查必须照常覆盖隐藏的标签，否则取消隐藏时标签已经跑偏了。
- **随手私记的展开态**：展开时这一行里带着 `me:` 和私记原文，任何「从当前行刷新锚点」的逻辑都不能在这时跑，否则私记原文会写进标签的身份 / 锚点里。
- **一行多签**：同一行的多条标签各编辑各的，悬停必须合成一个（编辑器对重叠装饰只显示一个悬停）。
